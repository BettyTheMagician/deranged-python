TermaChat Version 1.0
This is the first version (simple version) of a terminal chat text room. This is fully self hosted, includes a
client.py and server.py option in the main.py file, soon to be fully encrypted using the PAKE2 handshake method.

Currently utilising the socket, threading, time, colorama, os packages aswell as having the spake2 package imported
but the logic isn't currently finished/working. 

Will be regularly working on this repo, hope there are some use cases for it! 

Have other plans for this too, will reveal these at a later date when I have the project at a more suitable stage.

Thanks for viewing!
